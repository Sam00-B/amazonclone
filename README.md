# Amazon Clone
 
A front-end clone of Amazon built with HTML, CSS, and JavaScript. This is a learning project I made while following a YouTube tutorial to get started with JavaScript.
 
---
 
## About
 
I built this project to learn JavaScript basics in a practical way. Following along with a tutorial and building something familiar — like an Amazon clone — helped me understand how JS actually works in a real webpage, rather than just reading about it.
 
The main shopping and checkout flow (`index.html` and `checkout.html`) are fully functional and work in sync — you can add items to the cart and proceed to checkout. The orders and tracking pages are static, as the focus was on practicing JS fundamentals rather than building a complete app.
 
---
 
## Pages
 
- **index.html** — product listing / home page *(functional)*
- **checkout.html** — cart and checkout *(functional, synced with index.html)*
- **orders.html** — order history *(static)*
- **tracking.html** — order tracking *(static)*
---
 
## Tech Used
 
- HTML
- CSS
- JavaScript (vanilla)
---
 
## How to Run
 
Just clone the repo and open `amazon.html` in your browser. No installs needed.
 
```bash
git clone https://github.com/Sam00-B/amazonclone.git
cd amazonclone
open amazon.html
```
